# Paper — intro snippet

Tool-using language agents increasingly read untrusted documents before acting. An indirect prompt injection hidden in retrieved text can divert the agent from the user's task toward unauthorized tool calls. We introduce a small, auditable benchmark of paired attack and benign episodes with two mock tools, a frozen episode schema, and mechanical ASR/utility metrics. The harness records traces without enabling defenses, so later work can compare protection layers—including adaptive guards—against a fixed baseline.
