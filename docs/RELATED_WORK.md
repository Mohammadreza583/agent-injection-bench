# Related work (notes)

Indirect / prompt injection in LLM applications and agents:

- **Greshake et al.** — indirect prompt injection via retrieved/web content.
- **InjecAgent** — agent tool-use attack benchmarks and success criteria around tool misuse.
- **AgentDojo** — agent security environment / dynamic tool tasks.
- **Yi et al.** and follow-ons — benchmarking defenses and attack transfer.

This bench is intentionally **small and frozen** (20+20, two tools) to support auditable traces and later defense comparison in a **separate** codebase.
